Code for the Shock Corporation Systems Bot!!! Made by sillyeatsbilly

You must create a file called "config.json" where you will store your bot token in.

You need to install node.js before doing any of this as well!!!

Then using the terminal run "npm init -y" and then "npm install discord.js" this will install the correct packages! 

To run your bot run the command "node index.js" please note if you close VS Code or your computer/PC the bot will eventually go offline!
